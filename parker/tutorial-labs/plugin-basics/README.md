# Plugin basics lab

本目录是《从实践理解 DeepSeek Harness》2.1 节的可运行实验，代码取自官方 Cordis 教程的模式，并固定在仓库内，方便重复验证。

从仓库根目录运行：

```sh
cd parker/tutorial-labs/plugin-basics/tool-pipeline
node --import tsx ../../../../vendor/cordis/bin.js
```

```sh
cd parker/tutorial-labs/plugin-basics/lifecycle
node --import tsx ../../../../vendor/cordis/bin.js
```

```sh
cd parker/tutorial-labs/plugin-basics/dependency
node --import tsx ../../../../vendor/cordis/bin.js
```

三个实验均不读取 API Key，也不调用模型。
